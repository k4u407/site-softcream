# SOFT Ice Cream - Americana

Site da sorveteria SOFT Ice Cream feito como trabalho escolar por Thais e Miguel.

Feito a partir do template Feane (Free Html Templates / ThemeWagon), adaptado de hamburgueria para sorveteria,
com fotos e preços do cardápio oficial da SOFT.

Páginas: Início, Cardápio, Sobre e Contato. Para ver, abra o arquivo index.html.
